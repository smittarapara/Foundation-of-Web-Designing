# 📖 About This Repository

This repository contains laboratory practicals, HTML and CSS programs, assignments, term work, mini-project resources, and learning materials for the **Foundation of Web Designing (DSE1001C)** course.

The course provides hands-on experience in developing web pages using **HTML and CSS**, including webpage structure, multimedia, hyperlinks, tables, forms, semantic elements, responsive design, website publishing, and hosting fundamentals.

---

# 🎯 Course Objectives

The course aims to provide students with fundamental knowledge of web page development using HTML and CSS.

Students will learn to:

- Create and organize structured web pages.
- Add multimedia and forms to webpages.
- Apply CSS styling techniques.
- Develop responsive websites.
- Follow modern web development standards.
- Understand basic website publishing and maintenance.

# 🧪 Practical List

| No. | Practical Title |
|:---:|-----------------|
| 1 | Create a basic HTML webpage using HTML, HEAD, TITLE, and BODY tags, demonstrating headings, paragraphs, line breaks, horizontal rules, comments, and special character entities. |
| 2 | Create a webpage using ordered, unordered, description, and nested lists to represent structured content such as course modules or website menus. |
| 3 | Create a webpage using HTML5 semantic elements such as header, nav, section, article, aside, and footer, along with a consistent navigation structure. |
| 4 | Create a multi-page website using semantic elements and embed external content using iframe elements. |
| 5 | Create a personal profile webpage using text formatting tags such as b, i, u, strong, em, and mark to display personal and academic information. |
| 6 | Create a webpage using internal, external, email, and bookmark hyperlinks for navigation within and across webpages. |
| 7 | Create an image gallery webpage displaying images with appropriate attributes and hyperlinks. |
| 8 | Create a multimedia webpage integrating text, images, audio, and video elements with playback controls. |
| 9 | Create a timetable and product catalog using HTML table elements, including captions, headers, rowspan, colspan, and merged cells. |
| 10 | Apply CSS color, background, font, text, border, margin, padding, width, and height properties to enhance webpage appearance and layout. |
| 11 | Create a webpage demonstrating the CSS Box Model, display properties, and position properties for structured webpage layouts. |
| 12 | Create student registration, login, feedback, and contact forms using labels, text fields, radio buttons, checkboxes, buttons, and various HTML form controls. |
| 13 | Apply HTML5 input types including email, password, date, number, range, color, and file upload, along with form validation attributes such as required, pattern, min, max, minlength, and maxlength. |
| 14 | Design and develop a structured HTML5 webpage using semantic elements, meta tags, accessibility features, embedded multimedia such as YouTube and Google Maps, and hyperlinks. |
| 15 | Create a responsive multi-page website integrating semantic HTML, navigation menus, forms, multimedia content, tables, hyperlinks, and CSS styling. |

# 🎓 Course Outcomes

After completing this course, students will be able to:

- Understand the fundamentals of web technologies, website planning, and HTML document structure.
- Apply HTML elements, multimedia components, hyperlinks, tables, and semantic tags to create structured and interactive webpages.
- Apply CSS concepts, selectors, properties, and styling techniques to design responsive webpages.
- Analyze HTML forms, website structure, web hosting, and website publishing processes.
